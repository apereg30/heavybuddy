# heavybuddy

Heavybuddy je aplikace, která ti pomáhá sledovat tvé fyzické cíle.

Chceš se stát hasičem nebo hasičkou? Policistou nebo policistkou? Heavybuddy ti pomůže díky integrované infografice.

Zotavuješ se ze zranění? Aplikace tě upozorní na maximální váhu, kterou bys měl(a) při cvičení používat, abys si neublížil(a).
