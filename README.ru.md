# heavybuddy

Heavybuddy — это приложение, которое помогает отслеживать ваши физические цели.

Хотите стать пожарным? Полицейским? Heavybuddy поможет вам со встроенной инфографикой.

Восстанавливаетесь после травмы? Приложение предупредит вас о максимальном весе, который стоит использовать в упражнениях, чтобы не навредить себе.
