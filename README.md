# heavybuddy

Heavybuddy is an app that helps you track physical objectives.

Want to become a firefighter? Police officer? Heavybuddy helps you, with its integrated infography

Are you recovering from an injury? It alerts you of the maximun weight you should use on your exercises so you dont hurt yourself
