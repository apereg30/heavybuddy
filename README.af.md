# heavybuddy

Heavybuddy is 'n toepassing wat jou help om jou fisiese doelwitte op te spoor.

Wil jy 'n brandweerman of brandweervrou word? 'n Polisiebeampte? Heavybuddy help jou met sy ingeboude infografika.

Herstel jy van 'n besering? Dit waarsku jou oor die maksimum gewig wat jy in jou oefeninge moet gebruik sodat jy jouself nie seermaak nie.
