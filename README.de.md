# heavybuddy

Heavybuddy ist eine App, die dir hilft, deine körperlichen Ziele zu verfolgen.

Du möchtest Feuerwehrmann oder Feuerwehrfrau werden? Polizist oder Polizistin? Heavybuddy unterstützt dich mit seiner integrierten Infografik.

Erholst du dich gerade von einer Verletzung? Die App weist dich auf das maximale Gewicht hin, das du bei deinen Übungen verwenden solltest, damit du dich nicht verletzt.

## Probier es jetzt aus! Es ist kostenlos!
